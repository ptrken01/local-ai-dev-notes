# Gym Social Media Prompts: Common Pitfalls

When building AI workflows for fitness coaching, the difference between good and great prompts often lies in avoiding common traps that undermine conversion rates. Here's how to write prompts that actually work for client programs, social posts, and DMs.

## The Problem with Generic Prompts

Most coaches fall into the trap of using vague prompts like "Write a workout plan." These generate generic content that fails to convert because they lack specificity and context. A better approach uses structured templates that account for client demographics, goals, and program history.

## Working Prompt Structure

Here's a proven template for client program prompts:

```prompt
Create a 4-week hypertrophy program for a 28-year-old male who is 180cm tall, weighs 75kg, has 2 years of training experience, and wants to gain 5kg of muscle. Include:
- Weekly schedule with 4 sessions
- Exercise selection rationale
- Progression strategy
- Nutrition recommendations (2000-2200 calories)
- Rest day activities

Format as bullet points with clear headings.
```

This template works because it provides concrete data points that create specific, actionable content.

## Common Pitfalls to Avoid

### 1. Overgeneralization
Don't ask for "motivational posts" – specify the audience and purpose. Instead of "Write a motivational post," use:
```prompt
Write a 150-word Instagram caption for a 35-year-old female client who has lost 20kg in 6 months. Include her journey challenges, current achievements, and call-to-action for new clients.
```

### 2. Missing Context
Clients respond better to personalized content. A prompt without client history produces generic responses:
```prompt
Create a DM sequence for a client who has missed 3 consecutive workouts. Include empathy, follow-up questions, and program adjustment suggestions.
```

### 3. Inconsistent Formatting
Always specify output format. This prevents AI from generating unstructured content that's hard to implement.

## Conversion-Optimized Prompt Examples

For social posts:
```prompt
Write a Facebook post (200 words max) about strength training benefits for busy professionals. Include 3 key points, 1 personal anecdote, and 1 call-to-action. Use conversational tone.
```

For client DMs:
```prompt
Create a 3-part email sequence for a client who has completed their 8-week program but is struggling with consistency. Each message should be 100-150 words, include specific strategies, and build trust.
```

## FAQ

### Q: How many prompts do I need for effective workflow?
A: Start with 15-20 core prompts covering your most common scenarios. You can expand based on client diversity and program complexity. Most coaches find 50 prompts sufficient for comprehensive coverage.

### Q: Can these prompts work with any AI platform?
A: Yes, these templates are designed for universal compatibility across OpenAI, Claude, Gemini, and other major platforms. The structure remains consistent regardless of the specific model used.

### Q: How do I customize prompts for different client types?
A: Add specific demographic data to your base templates. For example, modify "28-year-old male" to "45-year-old female with knee issues" when targeting older clients or those with limitations.
