## The Working Prompt Template

```prompt
You are an expert course creator with 15 years experience. Create a detailed outline for [COURSE NAME] with [NUMBER] lessons. Each lesson should include:
- Title (1-2 words)
- Learning objective (1 sentence)
- Content structure (3-4 bullet points)
- Practice exercise (1 sentence)

Format as clean markdown with H2 headers for each lesson.
```

This template generates 50+ outlines in under 60 seconds, consistently producing usable content that saves hours of manual work.

2. **Execution**: Use any AI tool (ChatGPT, Claude, Gemini) with this exact prompt
